# Pivot Area Calculator
### حاسبة مساحة البيفوت — Offline PWA

**الإصدار:** 2.0  
**المنصة:** Android · iOS/iPadOS · Windows · macOS/Linux (المتصفحات الداعمة)  
**النوع:** Progressive Web App (PWA) · Offline-first · No Ads

---

## 1. نبذة عن التطبيق

**Pivot Area Calculator** هو تطبيق ويب احترافي لحساب مساحة البيفوت وعدد الجرر/المسارات وتوزيع المساحة حسب العجلات، مع واجهة عربية/إنجليزية ووضع ليلي.

تم تصميم التطبيق ليعمل كـ **PWA** بحيث يمكن تثبيته على الهاتف أو الكمبيوتر وفتحه كتطبيق مستقل بدون واجهة المتصفح بعد التثبيت.

### أهم المزايا

- يعمل **بدون إنترنت بعد أول زيارة ناجحة**.
- لا يحتوي على إعلانات.
- لا يعتمد على مكتبات أو خطوط خارجية لتشغيل الواجهة.
- يدعم Android وiPhone/iPad وWindows وأجهزة سطح المكتب الحديثة.
- يدعم التثبيت كتطبيق مستقل.
- زر التثبيت يظهر في أول استخدام فقط، ثم يختفي بعد التثبيت أو بعد إغلاق تعليمات التثبيت.
- يدعم العربية والإنجليزية.
- يحافظ على الأرقام باللغة الإنجليزية داخل البيانات والنتائج.
- يدعم الوضع الفاتح والداكن.
- يحفظ الإعدادات المحلية مثل اللغة والثيم والبيانات المخصصة على الجهاز.
- يحتوي على وسائل اتصال مباشرة: Email وLinkedIn وFacebook وX وGitHub وWhatsApp.

## 3. التشغيل بدون إنترنت

التطبيق يستخدم **Service Worker** لتخزين App Shell محليًا.

### الاستخدام الصحيح

1. افتح التطبيق لأول مرة من رابط HTTPS أو من خادم محلي.
2. انتظر حتى يتم تحميل الصفحة بالكامل.
3. بعد نجاح الزيارة الأولى، يمكن فتح التطبيق لاحقًا بدون إنترنت.
4. عند تثبيت التطبيق، يفتح من الأيقونة كتطبيق مستقل.

> **مهم:** فتح `index.html` مباشرة بالنقر عليه من مدير الملفات باستخدام `file://` لا يسمح للمتصفح بتشغيل Service Worker في أغلب المتصفحات. لذلك يجب استخدام HTTPS أو خادم محلي عند اختبار PWA والتثبيت.

## 4. التثبيت على Android

**Google Chrome / المتصفحات الداعمة:**

1. افتح التطبيق من رابط HTTPS.
2. يظهر زر التثبيت داخل التطبيق عند أول استخدام إذا لم يكن التطبيق مثبتًا.
3. اضغط زر التثبيت واتبع نافذة المتصفح.
4. بعد التثبيت يختفي زر التثبيت ويفتح التطبيق من الأيقونة كتطبيق مستقل.

إذا لم يظهر طلب التثبيت، استخدم قائمة المتصفح `⋮` ثم **Install app** أو **Add to Home screen** حسب المتصفح.

---

## 5. التثبيت على iPhone / iPad

Safari على iOS لا يوفر نفس `beforeinstallprompt` الموجود في Chrome على Android، لذلك التثبيت يتم يدويًا:

1. افتح التطبيق في Safari عبر HTTPS.
2. اضغط **Share / مشاركة**.
3. اختر **Add to Home Screen / إضافة إلى الشاشة الرئيسية**.
4. اضغط **Add / إضافة**.

بعد ذلك يظهر التطبيق كأيقونة مستقلة على الشاشة الرئيسية.

---

## 6. التثبيت على Windows

يفضل استخدام أحدث إصدار من **Microsoft Edge** أو **Google Chrome**:

1. افتح التطبيق من رابط HTTPS.
2. استخدم أيقونة التثبيت في شريط العنوان إن ظهرت.
3. أو افتح قائمة المتصفح واختر **Install app**.
4. بعد التثبيت سيظهر التطبيق كتطبيق مستقل ويمكن تشغيله من قائمة Start أو سطح المكتب حسب اختيارك.

> يمكن أيضًا تثبيت PWA على بعض بيئات macOS/Linux من المتصفحات الداعمة.

## 7. متطلبات PWA

للحصول على التثبيت والعمل الأوفلاين بشكل موثوق يجب نشر التطبيق عبر:

- `https://` في الاستضافة الفعلية، أو
- `http://localhost` أثناء التطوير المحلي.

**لا يُنصح باختبار التثبيت من ملف ZIP أو من `file://`.**

## 8. النشر على GitHub Pages

### إنشاء المستودع

```bash
git init
git add .
git commit -m "Release Pivot Area Calculator PWA"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/pivot-area-calculator.git
git push -u origin main
```

### تفعيل GitHub Pages

1. افتح المستودع على GitHub.
2. ادخل إلى **Settings → Pages**.
3. اختر **Deploy from a branch**.
4. اختر `main` والمجلد `/ (root)`.
5. احفظ الإعدادات.
6. افتح رابط GitHub Pages من الهاتف أو الكمبيوتر.

بعد أول زيارة ناجحة يستطيع Service Worker تخزين ملفات التطبيق للعمل أوفلاين.

## 9. الخصوصية والبيانات

- لا توجد إعلانات داخل التطبيق.
- لا يحتاج التطبيق إلى حساب مستخدم لتشغيل الحاسبة.
- إعدادات التطبيق والبيانات التي يتم حفظها محليًا تستخدم `localStorage` على الجهاز.
- روابط وسائل التواصل تفتح الخدمات الخارجية عند اختيار المستخدم لها، وقد تحتاج اتصالًا بالإنترنت.
- تشغيل الحاسبة نفسها لا يحتاج إلى اتصال خارجي بعد التخزين المحلي الناجح.
